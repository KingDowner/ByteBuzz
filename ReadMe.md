ByteBuzz 🚀

ByteBuzz is a beginner-friendly JavaScript project that uses loops and conditional statements to replace numbers with words based on divisibility.

How It Works

The program counts from 1 to a selected maximum number between 1 and 30.

Multiples of 3 print Byte.

Multiples of 5 print Rush.

Multiples of both 3 and 5 print ByteRush.

All other numbers print normally.

The program also validates that the selected number is within the allowed range before running the loop.

Technologies Used

JavaScript

Node.js

How to Run

Open bytebuzz.js in VS Code.

Change the myNumber variable to a number between 1 and 30.

Run the following command in the terminal:

node bytebuzz.js
